# 无法登录处理规范

文档编号：KB-LOGIN-001
适用场景：用户反馈无法登录、登录报错、账号被锁定、收不到验证码
关键词：登录、密码、验证码、账号锁定、认证、SSO
相关文档：KB-STATUS-001（工单状态流转规则）、KB-PAYMENT-001（支付成功但订单未更新）

## 需要收集的信息

先按顺序确认下面五项，缺一项不要急着下结论：

| 信息 | 说明 | 为什么需要 |
|---|---|---|
| 账号 | 手机号、邮箱或工号，确认用户实际输入的是哪一个 | 多账号场景下，报错常来自另一个账号 |
| 登录方式 | 密码、短信验证码、扫码、SSO | 不同方式的失败原因完全不同 |
| 报错原文 | 截图或文字，含错误码 | “登录失败”太笼统，无法定位 |
| 发生时间 | 具体时间点，是否连续多次出现 | 区分偶发与持续故障 |
| 终端与网络 | App 或浏览器版本、Wi-Fi 还是移动网络、是否挂代理 | 客户端缓存和网络是高频原因 |

## 排查步骤

1. **账号是否存在且可用**
   - 核对账号是否拼写错误、是否已注销。
   - 是否因多次密码错误被临时锁定；锁定一般在 30 分钟后自动解除。
2. **密码类问题**
   - 忘记密码：引导走“找回密码”，前提是绑定的手机号或邮箱可用。
   - 提示密码错误但用户确信正确：检查大小写、输入法全半角、首尾空格。
3. **验证码类问题**
   - 手机号是否与账号绑定一致，是否填错国家码。
   - 短信延迟常见 1~2 分钟；短时间重复获取会触发频率限制，需要等待后再试。
4. **客户端与环境**
   - 清理缓存，或换浏览器、换设备复现，排除本地状态问题。
   - 挂 VPN 或代理可能触发地域风控拦截。
5. **权限与组织**
   - 账号是否被管理员停用、是否被移出组织。
   - 同一组织内其他人能否登录：能则是个体问题，不能则按系统故障处理。

## 判断与处理动作

| 判断 | 处理动作 |
|---|---|
| 忘记密码或填错账号 | 指导自助找回，不建工单 |
| 验证码收不到 | 指导更换获取方式；超过 10 分钟仍收不到再建工单 |
| 客户端缓存或版本过低 | 指导清理缓存或升级版本 |
| 账号被锁定、停用，或需要改绑手机号 | 记录工单，转人工处理 |
| 多个用户同时无法登录 | 按系统故障升级，立即转人工 |

## 转交人工的条件

- 需要后台操作：解锁账号、启用或停用账号、改绑手机号或邮箱。
- 疑似账号被盗：异地登录、密码被改、收到非本人操作的通知。
- 同一时间多人无法登录，或登录接口返回 5xx。
- 需要查看服务端日志或登录审计记录才能定位的问题。

## 注意事项

- 不要向用户索要或记录明文密码、短信验证码。
- 不要引导用户关闭安全验证后重试。
- 结论要落到“下一步做什么”，不要只回复“已排查”。
